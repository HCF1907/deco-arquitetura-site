# Site da DECÔ Arquitetura & Interiores

Site institucional do escritório DECÔ — Arquitetura & Interiores,
Ribeirão Preto/SP.

Estático: um `index.html` e a pasta `assets/`. Não há build, não há
dependência. Abre com dois cliques, inclusive offline.

## Publicação

Os arquivos ficam na raiz, então serve igual nos dois caminhos:

- **GitHub Pages** — branch `main`, pasta `/` (raiz)
- **Netlify** — `netlify.toml` já configurado (`publish = "."`)

Qualquer push em `main` republica.

## Origem

O trabalho de origem, o briefing, a identidade e a lista de pendências
ficam no repositório interno da Hella, não aqui.
